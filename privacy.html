Privacy Policy — Sochnye Momenty Uploader

Last updated: 8 October 2026

Who uses this application

Sochnye Momenty Uploader is a private desktop tool. It is used only by its owner, Anatoliy Krotov, to manage videos on the owner's own YouTube channel(s). It is not offered to the public, and no other person signs in to it.

YouTube API Services

The application uses YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

  • The owner's own channel information and the statistics of the owner's own videos (to track views).
  • The owner's own videos, in order to upload them and to edit their titles, descriptions or privacy settings.

The application does not access data of any other YouTube user.

How data is stored and shared

OAuth tokens and view statistics are stored only on the owner's own computer. No data is sold, shared with or transferred to third parties.

How to revoke access

Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions. Deleting the local token file also removes all stored access.
